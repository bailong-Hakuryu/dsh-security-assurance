# Export UI previews Profile and destination while Service performs Delivery

For a SEALED Assessment, the Workbench selects an authorized Export Profile and Host-registered Delivery Destination and displays a Service-derived Export Preview of included field categories, redactions, artifact format, destination summary, expiry and warnings. It then submits a durable Export Request and observes its Receipt and status; the browser does not construct canonical reports, choose arbitrary filesystem or network targets, access credentials, or write the artifact. Download uses the Host's short-lived one-use capability after reauthorization.
