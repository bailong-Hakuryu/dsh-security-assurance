# Analyzer capabilities use a versioned taxonomy

Analyzer capability claims use a versioned core Capability Vocabulary for Assessment modes, ecosystems, Coverage dimensions, Evidence schemas, execution classes, resources, and Data Egress requirements. Vendor or experimental extensions require collision-resistant namespaces and may not redefine a core meaning. Unknown mandatory capabilities, versions, or constraints fail composition; unknown optional extensions are retained as metadata but never counted toward required Coverage or authority.
