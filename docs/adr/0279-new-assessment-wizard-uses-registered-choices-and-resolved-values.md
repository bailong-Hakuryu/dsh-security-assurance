# New Assessment Wizard uses registered choices and resolved values

The New Assessment Wizard selects only authorized Repository Registry entries, supported Modes and Profiles from the Security Catalog, and a mode-specific Target Selector, with an optional predeclared stronger-controls request. It displays Service-resolved labels and constraints but accepts no arbitrary root, Provider, Analyzer, Policy, command, secret, or free-form security prompt. Submitting constructs the exact versioned Start Assessment Request and idempotency identity rather than a browser-owned configuration object.
