# Deterministic Reference Fakes exercise official seams

Versioned Reference Fakes implement the public Analyzer, Provider, Evidence Key Provider, broker, and clock contracts and can deterministically emit success, failure, timeout, malformed output, delayed fenced result, budget overrun, key loss, and other declared scenarios. They are registered and governed like real contributions and therefore prove orchestration and failure Conformance without reaching external services. Fake results are labeled test-only and never count as Security Effectiveness, Analyzer Qualification, Support Claims, or customer Evidence.
