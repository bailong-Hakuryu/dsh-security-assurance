# Independent Validation is established from the provenance graph

Independence is computed from the complete provenance graph of Candidate, model, Provider, Prompt, Analyzer, Tool, Evidence source, prior contributions, and ancestor inputs rather than from different Attempt IDs or role labels alone. Each Validation Contract states which shared ancestry is disallowed or permitted for its weakness and proof type. A self-validation path is eligible only for a deterministic Analyzer whose qualified contract explicitly proves the claim; model-originated Candidates require a distinct qualifying validation lineage.
