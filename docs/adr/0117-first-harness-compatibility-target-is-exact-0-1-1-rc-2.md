# First Harness compatibility target is exact 0.1.1-rc.2

The first qualified plugin build targets DeepSeek Harness `0.1.1-rc.2` exactly and proves that combination through packed-profile installation and compatibility probes on every supported operating system. The Security Support Matrix expands one Harness version at a time only after equivalent evidence; the package neither claims an untested `^0.1` range nor maintains a Harness fork.
