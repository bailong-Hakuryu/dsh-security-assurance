# The Transition Matrix receives model-based Conformance

State-machine Conformance generates valid and invalid sequences of every public Assessment Command, revision, idempotency key, authority, failure, cancellation, Resume, Risk Decision, and sealing condition. The pure Kernel model predicts the allowed result, state, revision, and invariant set, and the same sequence executes against the packed public Service for comparison. Shrunk failing sequences become permanent regression cases, while example-path unit tests alone cannot claim lifecycle completeness.
