# Technical Severity uses a versioned Evidence-derived method

Technical Severity is calculated through a versioned Severity Method over Evidence-backed impact, exploit preconditions, attacker position, affected scope, control strength, and other declared dimensions. Model, scanner, or human scores are retained as observations but do not directly set the canonical value, and unknown dimensions remain explicit rather than receiving optimistic defaults. The method, vector inputs, calculation result, uncertainty, and Evidence Links are frozen separately from Policy Significance and Risk Acceptance.
