# Resume preserves the frozen Assessment contract

Resume is allowed only under the original frozen Subject, Policy, Coverage Plan, Provider Composition, Assessment Budget, and other semantic inputs. It creates new Attempts for incomplete or explicitly retryable nodes while retaining every prior Attempt and interruption record; it does not reinterpret completed Evidence or silently replay successful work. Any semantic change, including a new snapshot, policy, plan, provider composition, or budget, requires a new Assessment.
