# Deterministic-only Profiles are explicit and cannot impersonate Agent Coverage

The product may expose a separately named and qualified deterministic-only Assessment Profile whose Coverage Plan contains no governed Role obligation. If Standard, Deep, or another selected Profile requires a Role Agent and no eligible model Provider is available, the Assessment blocks and can eventually resolve only through its declared Coverage rules, never by relabeling Analyzer output as an Agent contribution or calling an unapproved model. Reports and Support Claims distinguish deterministic-only capability from complete model-assisted coverage.
