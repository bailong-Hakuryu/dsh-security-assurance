# Policy Significance is derived by a deterministic rule trace

For each validated Finding, the Policy Evaluator derives Policy Significance from the exact Policy rule, Subject and exposure scope, Technical Severity vector, Evidence Confidence requirements, Finding freshness and lineage, applicable immutable Risk Acceptance, and proved compensating controls. Analyzer labels, Role recommendations, user interface choices, and aggregate scores cannot directly set or lower significance. The selected rule and every input are preserved in an Evaluation Trace while the Finding and Technical Severity remain unchanged.
