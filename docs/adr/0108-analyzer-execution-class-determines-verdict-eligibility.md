# Analyzer execution class determines verdict eligibility

Every Analyzer is frozen as Pure, Constrained Process, Governed Agent, or External Provider execution. Registration alone grants no authority: verdict eligibility is derived from its descriptor, Provider identity, live Backend Probe, Evidence and Coverage Contracts, Data Egress Contract, and Policy. An Analyzer that cannot prove the required boundary may contribute Advisory Findings but cannot satisfy required Coverage or support an Assurance Submission.
