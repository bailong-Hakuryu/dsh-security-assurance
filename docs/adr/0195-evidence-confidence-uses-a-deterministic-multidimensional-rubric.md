# Evidence Confidence uses a deterministic multidimensional rubric

Evidence Confidence is derived by a versioned rubric over proof completeness, source and producer qualification, reproducibility, independence, Subject binding, freshness, negative controls, and remaining Proof Gaps. It is not the model's stated probability, an average of agent votes, Technical Severity, or Policy Significance. The rubric retains its component grades and deterministic result so a report can explain exactly which evidentiary weakness lowered confidence.
