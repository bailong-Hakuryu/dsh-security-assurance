# Workbench information architecture is fixed for v0.1

The first Workbench contains Overview, Repositories, New Assessment, Assessment Detail, Findings, Evidence, Risk Decisions, Exports, and Runtime Health views. Each view is a projection over one or more public Service operations and does not create a hidden client-only domain. New navigation or actions require an existing or reviewed Service contract rather than direct database, filesystem, Provider, or browser authority.
