# Workbench E2E uses a packed Host, real browser, and real authority

Workbench E2E starts the packed Client and Service entries in the Reference Test Host and drives a real supported browser through start, revision waiting, progress, BLOCKED diagnosis, Resume, cancellation, Host-authorized Risk Decision, Seal, Finding and Evidence disclosure, export, reload, reconnect, HMR, and denied actions. Tests verify keyboard and focus behavior, accessibility semantics, redaction, bounded rendering, and that protected payloads and export locations do not enter URL, browser history, console, or unauthorized DOM; component snapshots alone are insufficient.
