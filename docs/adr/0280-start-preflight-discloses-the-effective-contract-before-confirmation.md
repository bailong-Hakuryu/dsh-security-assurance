# Start Preflight discloses the effective contract before confirmation

Before the user confirms start, the Workbench presents an authorized Start Preflight derived by the Service showing Subject kind and target, effective Policy and Profile identities, Provider Composition summary, Data Egress destinations and categories, Evidence Protection, maximum budget, known unsupported conditions, and claim and Coverage limitations. Confirmation may accept or cancel that resolved proposal but cannot edit it; any changed selection requests a new preflight so displayed consent and the admitted frozen contract share one digest.
