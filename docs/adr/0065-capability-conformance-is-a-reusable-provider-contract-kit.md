# Capability Conformance is a reusable Provider contract kit

The Capability Conformance Test Kit exercises commands and every state transition; frozen Subject, Policy, and Composition; deterministic Verdicts; Evidence, Seal, Bundle, and Submission contracts; crash, recovery, cancellation, and budget failure; all authorities; key and schema failure; retention; multi-process races; and packed Harness installation. Built-in and third-party Providers must pass the same applicable contracts.
