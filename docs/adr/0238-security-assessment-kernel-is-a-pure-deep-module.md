# Security Assessment Kernel is a pure deep Module

The package-private Security Assessment Kernel accepts canonical immutable domain values through a small Interface equivalent to `applyAssessmentCommand`, `compileCoveragePlan`, `evaluatePolicy`, and `checkSealReadiness`. It returns Kernel Decisions, new aggregate values, Journal Facts, work intents, Evaluation output, or invariant violations and performs no SQLite, filesystem, process, network, clock, Cordis, model, encryption, or artifact I/O. Equal canonical inputs and Kernel version produce equal semantic outputs, concentrating state and Verdict rules in one testable Module.
