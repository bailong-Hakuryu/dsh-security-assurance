# Coverage hierarchy requires every mandatory child

A composite or parent obligation is satisfied only when every mandatory descendant resolves `SATISFIED` or is independently proved `NOT_APPLICABLE` under the parent's aggregation rule. One child's stronger Evidence, many easy completions, high file coverage, or an aggregate score cannot compensate for another mandatory child's `GAP`. Coverage Aggregation preserves each child status and reason so a parent result remains fully explainable rather than reducing the graph to a percentage.
