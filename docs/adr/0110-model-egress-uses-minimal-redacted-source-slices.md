# Model egress uses minimal redacted Source Slices

Security Role Agents and external model Analyzers receive only purpose-specific Source Slices selected for their frozen task, checked for secrets and required redaction, and recorded by category and digest against an explicit model Provider destination. Their tool composition excludes Web and arbitrary network tools; inability to satisfy the Data Egress Contract prevents verdict-eligible execution rather than widening disclosure.
