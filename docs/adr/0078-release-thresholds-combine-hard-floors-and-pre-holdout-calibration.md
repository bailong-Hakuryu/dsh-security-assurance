# Release Thresholds combine hard floors and pre-Holdout calibration

The Release Constitution fixes non-negotiable Hard Safety Floors now and calibrates statistical Effectiveness and Utility thresholds only from Development and Qualification evidence before freezing them for Release Holdout. Hard floors require complete Conformance, no unauthorized code, network, Tracking, or Risk Acceptance action, no forged or corrupt canonical Evidence acceptance, no hidden Critical defect receiving `SATISFIED`, and no Ground Truth Leakage; blocking every case as indeterminate cannot pass the later Valid Approval Yield threshold.
