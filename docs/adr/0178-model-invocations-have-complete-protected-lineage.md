# Model invocations have complete protected lineage

Every Role model call creates a Model Invocation Record binding Provider and backend, deployment and model identity, Moving Provider status, Role and Prompt versions, Prompt and Tool Schema digests, Context Grant digest, parameters and randomness strategy, start and finish times, token and request usage, response digest, finish reason, broker diagnostics, and parent Attempt. Sensitive prompt, source, and response payloads remain protected Evidence under retention and disclosure Policy, while their lineage is present in the canonical Assessment Bundle.
