# Finding triage View keeps domain dimensions separate

The Findings view groups and filters by Policy Significance, Technical Severity, Validation Outcome, Evidence Confidence, weakness, component, sensitivity, and Coverage relation while visibly distinguishing Candidate, VALIDATED Finding, Rejected Candidate, and Unresolved Candidate records. It does not reduce them to one risk score, sort solely by scanner order, relabel unresolved work as false positive, or let the user edit validation. Candidate Cluster and Finding Lineage relations remain navigable without visually merging identities.
