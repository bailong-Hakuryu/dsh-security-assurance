# Coverage Obligations are stable typed completion contracts

Every Coverage Obligation has a stable Assessment-local identity and versioned definition binding its Security Requirement, Subject scope selector, component and weakness dimensions, mandatory or advisory significance, required Evidence and independence, eligible Provider and Analyzer conditions, dependencies, budget class, and exact completion and not-applicable rules. An Analyzer name, task description, file count, or successful process exit is not an obligation. The canonical Bundle preserves each obligation definition independently of its later resolution.
