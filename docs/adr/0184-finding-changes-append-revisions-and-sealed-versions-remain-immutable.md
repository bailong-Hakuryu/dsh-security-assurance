# Finding changes append revisions and sealed versions remain immutable

While an Assessment remains open, any correction, classification refinement, severity update, or Evidence-backed conclusion change appends a Finding Revision linked to the prior revision with a reason, actor, inputs, and aggregate revision. Finding Supersession selects the current revision without deleting history or changing the Assessment-local Finding ID. Sealing freezes the complete revision chain and current selection; later corrections, remediation, or closure require new linked records or a new Assessment and never rewrite a SEALED Finding.
