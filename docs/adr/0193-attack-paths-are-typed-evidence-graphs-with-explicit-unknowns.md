# Attack Paths are typed Evidence graphs with explicit unknowns

An Attack Path Graph contains typed nodes and Evidence-backed edges for entry conditions, attacker capabilities, preconditions, assets, trust-boundary crossings, controls, bypasses, sinks, and impact. Each edge carries support, direction, assumptions, and an explicit known, disproved, or unknown state; narrative diagrams and prose are derived views. Policy and the Validation Contract decide when path completeness is required, so an Unknown Edge creates a visible Proof Gap and absence of a remote path cannot erase a separately proved local security invariant.
