# Deterministic failures cannot be erased by reruns

A deterministic Conformance, lifecycle, platform, artifact, Mutation, or Resource failure remains a release failure even if a diagnostic rerun later passes; investigation must explain and correct the original result before new qualification. Model-assisted evaluations run only their pre-registered independent repetitions and report the full distribution. Proven benchmark infrastructure or Corpus corruption invalidates the complete affected Case for every Arm under the same rule, while product crashes, timeouts, budget exhaustion, and incorrect outcomes remain product results and are never selectively rerun away.
