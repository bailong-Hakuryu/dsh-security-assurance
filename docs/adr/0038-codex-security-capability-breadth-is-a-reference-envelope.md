# Codex Security capability breadth is a reference envelope

DSH Security Assurance uses the publicly documented Codex Security capability breadth as a product reference, including standard, deep, and change assessment; threat modeling, discovery, validation, path and impact analysis; triage, remediation and verification; hardening, reporting, export, tracking, workbench, CLI, SDK, batch, and CI surfaces. DSH redefines these behaviors through its own public contracts and separates them into the read-only Security Assessment Kernel, explicitly authorized Security Remediation Workflow, and explicitly authorized Security Delivery Workflow rather than copying Codex-private implementation or authority.
