# All public surfaces pass one semantic parity suite

One Surface Parity Suite expresses public Assessment scenarios independently of transport and runs them through the direct Service contract, model function tools, package-owned Typert Remote, and Engineering Control Plane Provider adapter. It compares domain outcomes, revisions, state, Verdict, and artifact identities while also checking each surface's authority derivation, disclosure, pagination, cancellation, and error mapping. An adapter may narrow a view but cannot invent alternate lifecycle or mutation semantics.
