# Coverage planning requires an Evidence-backed Subject Inventory

Before a complete Coverage Plan is admitted, the Inventory phase establishes Evidence-backed components, languages, package and dependency graphs, configuration, execution and lifecycle surfaces, entry points, trust boundaries, generated or excluded material, and child Subjects under frozen inventory rules. Inventory Completeness is checked against the selected Mode and Profile rather than inferred from a directory listing or model summary. Unknown, unreadable, truncated, or unsupported relevant regions become typed Inventory Gaps that generate or block Coverage obligations.
