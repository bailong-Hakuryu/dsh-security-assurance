# Workbench inherits Host web security and is accessible and bilingual

The Client entry inherits and complies with Host CSP, origin, session, request-forgery, remote-asset, download, and telemetry controls and loads no unnecessary third-party script, font, tracker, analytics endpoint, or remote content. One-use download capabilities never enter URLs or browser history and every privileged action is protected by Host channel authority. The first UI supports keyboard navigation, predictable focus and overlay return, semantic labels, non-color-only states, bounded responsive rendering, and complete English and Simplified Chinese product strings without translating canonical machine identifiers.
