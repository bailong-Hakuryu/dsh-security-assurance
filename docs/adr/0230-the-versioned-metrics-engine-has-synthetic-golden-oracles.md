# The versioned Metrics Engine has synthetic Golden oracles

A pure versioned Metrics Engine consumes immutable Evaluation Run Bundles, one-to-one matches, adjudications, preclassified failures, budgets, and stratum definitions to calculate every Effectiveness, Utility, uncertainty, and non-inferiority measure. Synthetic Golden cases fix expected denominators and outputs for misses, duplicates, false positives, unresolved and indeterminate results, crashes, exclusions, insufficient strata, and paired Arms. Reports render engine output and never implement independent spreadsheet or template formulas.
