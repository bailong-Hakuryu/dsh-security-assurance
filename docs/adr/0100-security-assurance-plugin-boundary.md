# Security Assurance Plugin Boundary

Security Assurance is an independent plugin that integrates only through public Harness capability seams, Cordis lifecycle, tools, Typert Remote, Client slots, and bundle composition. It does not modify Harness Core, patch `agent-loop`, require a Harness fork, or copy Harness source into the product; `D:\Deepseek\deepseek-harness-master` remains a read-only compatibility and test reference.
