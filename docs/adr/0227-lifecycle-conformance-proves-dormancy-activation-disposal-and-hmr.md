# Lifecycle Conformance proves dormancy, activation, disposal, and HMR

Lifecycle Conformance verifies that installation and dormant entry points create no Service, tool, Remote, Client slot, process, timer, database, Evidence path, or network side effect. It then tests activation, partial bundle composition, dependency loss, disposal, compatible and incompatible HMR, reactivation, and uninstall, proving that every Fiber-owned registration, lease, long poll, process tree, broker request, staging object, and handle is quiesced or durably interrupted according to contract. Killing the Host is not accepted as cleanup.
