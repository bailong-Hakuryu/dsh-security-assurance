# Hostile repositories are first-class Conformance Subjects

Adversarial Repository Fixtures exercise prompt injection, links and path escapes, special or oversized files, malicious archives and command arguments, forged Findings, Coverage, Seals and Analyzer output, repository attempts to weaken Policy, resource exhaustion, and hostile Patch or Artifact content. Repository-controlled data is never treated as trusted instruction or canonical Evidence.
