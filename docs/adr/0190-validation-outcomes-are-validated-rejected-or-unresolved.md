# Validation Outcomes are VALIDATED, REJECTED, or UNRESOLVED

Every admitted Candidate receives at most one current Validation Outcome under an exact contract revision: `VALIDATED` when eligible Evidence proves the security claim, `REJECTED` when eligible Counter-Evidence proves the applicable rejection condition, or `UNRESOLVED` when neither burden is met. Each outcome records reasoning, Evidence Links, independence, Proof Gaps, and lineage. Model confidence, elapsed time, lack of an exploit, or a scanner label cannot collapse this three-way state into a guessed Boolean.
