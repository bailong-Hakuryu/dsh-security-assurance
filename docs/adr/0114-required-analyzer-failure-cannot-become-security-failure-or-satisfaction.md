# Required Analyzer failure cannot become Security failure or satisfaction

A recoverable failure of an Analyzer required by the Coverage Plan places the Assessment in `BLOCKED` and preserves the failed Attempt for explicit resume. If continuation is no longer possible or the frozen budget is exhausted, Coverage Reconciliation records the missing obligation and the Assessment may seal only as `INDETERMINATE`; only validated Policy-blocking risk yields `FAILED`, and missing execution can never yield `SATISFIED`.
