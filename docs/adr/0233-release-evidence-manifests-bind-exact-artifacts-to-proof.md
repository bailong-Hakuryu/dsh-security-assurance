# Release Evidence Manifests bind exact artifacts to proof

Each candidate produces a machine-readable Release Evidence Manifest binding the exact packed artifact and dependency lock digests to source revision, Harness target, Capability Conformance, platform, Workbench, lifecycle, fault, race, Mutation, Resource, Effectiveness, Utility, Dogfood, Security Support Matrix, known limitations, Risk Acceptances, and Evaluation Run Bundle identities. Promotion verifies this manifest and every required Evidence digest against the Release Constitution; a CI URL, badge, README claim, or test count is not equivalent release proof.
