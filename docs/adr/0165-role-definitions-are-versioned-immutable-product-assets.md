# Role Definitions are versioned immutable product assets

Each catalog entry is a versioned Role Definition binding stable role identity, system Prompt and digest, compatible model requirements, Role Tool Manifest, input and output schemas, default budget ceiling, independence class, and compatibility constraints. Definitions are package-owned, validated, and frozen into Provider Composition before execution; repository files and start requests may supply task data but cannot edit a Role Definition. Any semantic change to a definition creates a new version and requires applicable requalification.
