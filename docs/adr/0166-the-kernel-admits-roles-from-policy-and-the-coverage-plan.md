# The Kernel admits Roles from Policy and the Coverage Plan

The Assessment Kernel alone performs Role Admission from the frozen Security Policy, Assessment Profile, Coverage Plan, available qualified Providers, independence requirements, and Assessment Budget. A caller may select an authorized named Profile or request stronger treatment, but cannot directly set role count, prompts, model, tools, independence, or gate-bearing status. Role Agent suggestions are proposals to the Kernel and never self-authorization for additional execution.
