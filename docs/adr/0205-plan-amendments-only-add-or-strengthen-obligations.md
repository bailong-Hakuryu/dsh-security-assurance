# Plan Amendments only add or strengthen obligations

Security-relevant scope or facts discovered after initial compilation may produce an append-only Plan Amendment that records triggering Evidence, deterministic rule, added or strengthened obligations and edges, provider and budget impact, prior and new plan digests, and aggregate revision. An amendment cannot delete, weaken, mark complete, reinterpret, or silently reorder an existing mandatory obligation. If the frozen budget or qualified composition cannot execute the expanded plan, the new obligation remains a visible Coverage Gap rather than disappearing.
