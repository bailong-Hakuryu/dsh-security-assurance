# Gate-bearing Analyzers require scoped Qualification Records

Registration alone never grants gate-bearing status. The exact Analyzer Identity and build digest must pass the applicable Capability Conformance suite, adversarial repository fixtures, execution-isolation checks, Evidence and failure contracts, and Effectiveness requirements before a Host-trusted Analyzer Qualification Record is issued. That record states its supported ecosystems, modes, Coverage dimensions, execution backend, Providers, platforms, known limitations, issuer, evidence digests, and expiry; missing, incompatible, or expired qualification limits the Analyzer to Advisory contribution.
