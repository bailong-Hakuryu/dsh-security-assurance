# TS JS Node support uses a hybrid Analyzer Portfolio

Complete v0.1 TS, JS, and Node coverage is supplied by a frozen hybrid Portfolio: deterministic Subject Inventory; dependency, lockfile, and lifecycle-script inspection; redacting secret detection; configuration, permission, and trust-boundary rules; AST source/sink and taint analysis; and governed Threat, Discovery, Validation, and Attack Path Role Agents. Third-party scanners remain separate registered Providers and gain verdict eligibility only through the same qualification contracts.
