# Role Detail is immutable and cannot accept ad-hoc instructions

An authorized Role Detail View renders immutable Role Contribution fields, Follow-up Requests, Challenge Packages and responses, lineage, and a separately authorized redacted Transcript View. The user cannot edit a contribution, append a prompt, resume a model conversation, change tools, or directly spawn another Role from this view. Any additional analysis follows a reviewed Service command and Kernel-admitted durable Attempt rather than an unrecorded mid-run instruction.
