# Finding Resolution requires a new sealed Assessment

Applying a Patch Artifact never closes a Finding. The patched code becomes a new immutable Subject whose Fix Verification checks the strongest original proof, safe fail-before/pass-after regression behavior when practical, legitimate behavior, nearby bypasses, Change Impact Cone, and relevant repository tests; only a new sealed Assessment may establish resolved Finding Lineage, while any material Proof Gap leaves the Finding open.
