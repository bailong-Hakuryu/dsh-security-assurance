# Transport Adapters contain no domain Policy

Model tools, Typert Remote handlers, Workbench bindings, Control Plane Provider integration, and future CLI or SDK Adapters derive a trusted channel into a Security Invocation, validate transport framing, map cancellation, invoke one Security Service operation, and translate the resulting DTO or Security Result. They do not compile Policy, decide authority, mutate Stores, calculate Coverage or Verdicts, perform hidden retries, alter redaction, or maintain a parallel state machine. Fixing domain behavior in the Service therefore fixes every Adapter.
