# Proof runs in PR, Nightly, Weekly, and RC tiers

PR runs deterministic Conformance, micro-Corpus, and adversarial smoke tests; Nightly adds Standard Effectiveness, fault, and integration tests; Weekly adds Deep repetitions, platform, and performance proof; RC runs the sealed Holdout, all Evaluation Arms, packed Harness installation, and blinded adjudication.
