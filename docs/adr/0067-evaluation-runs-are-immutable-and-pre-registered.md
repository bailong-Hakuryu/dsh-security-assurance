# Evaluation Runs are immutable and pre-registered

Each experiment produces an Evaluation Run Bundle binding Corpus and Ground Truth versions, exact Harness and product builds, model and role identities, prompts, Analyzers, Policy, Profile, budgets, randomness, raw outputs, matching, adjudication, metrics, cost, and failures. Benchmark definitions and Release Thresholds are frozen before execution and cannot be edited post hoc to make a run pass.
