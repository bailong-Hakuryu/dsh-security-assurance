# Evidence kinds use a versioned core registry

The Evidence Type Registry defines versioned schemas and validation rules for core Source Slice, Static Trace, Dependency Match, Configuration Proof, Safe Reproducer, Negative Control, Attack Path Graph, and Human Attestation Evidence. Additional kinds require namespaced identities, registered schemas, protection rules, and explicit Validation Contract support; unknown types remain opaque and ineligible for mandatory proof. Markdown, logs, screenshots, and scanner reports may be source artifacts but do not gain semantic Evidence meaning without an admitted typed record.
