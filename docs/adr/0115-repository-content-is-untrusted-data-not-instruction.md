# Repository content is untrusted data not instruction

Every Subject filename, document, comment, generated artifact, and discovered instruction is treated as untrusted repository data. Source is structurally delimited and minimally sliced, Security Role tools are allowlisted, contributions must satisfy strict output schemas and Kernel validation, and repository content cannot register an Analyzer, select a Provider, weaken Policy, expand egress, or modify Role instructions.
