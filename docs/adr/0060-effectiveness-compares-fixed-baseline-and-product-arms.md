# Effectiveness compares fixed baseline and product Arms

Evaluation compares ordinary Harness single-agent work, Harness with ordinary subagents, deterministic security tools, Security Assurance Standard, Security Assurance Deep, and Control Plane plus Security Assurance end to end, with Codex Security optional as a reference Arm. Results include Matched-budget and native-profile views so additional compute is reported rather than hidden.
