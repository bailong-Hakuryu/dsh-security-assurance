# Assessment roles come from a fixed Security Role Catalog

The first Assessment release admits only the governed `threat-modeler`, `discovery-analyst`, `validation-analyst`, `attack-path-analyst`, and `challenge-analyst` roles from a versioned Security Role Catalog. They may produce specialized analysis and Evidence proposals but none is an Approver, Risk Acceptor, Decision Authority, Policy Evaluator, or Security Verdict owner. A caller, repository, model, or Analyzer cannot invent an executable role name or turn a conversational persona into an Assessment participant.
