# Evidence Contracts not Agent votes determine convergence

Agreement count, majority vote, model confidence, eloquence, or execution order never validates or dismisses a security claim. Deterministic Evidence Convergence evaluates each candidate and challenge under the applicable Validation Contract, independence requirements, Evidence eligibility, Finding identity rules, and Coverage obligation. Unresolved disagreement remains an Unresolved Candidate or Proof Gap and, when it leaves mandatory Coverage incomplete, can support only an `INDETERMINATE` outcome rather than a synthetic consensus.
